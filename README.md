## 📖 About StoryVerse

**StoryVerse** is a cinematic, interactive storytelling platform built with **Next.js 14**, **React Three Fiber**, **GSAP**, and **Tailwind CSS**. It blends the aesthetic of a modern streaming service with the interactivity of a narrative game.

### ✨ Features (WIP)
- **Three Age‑Separated Zones** — Everyone, Teen, and Mature (psychological, no explicit content)
- **12 Unique Stories** with branching decision trees
- **3D Animated Backgrounds** using WebGL (stars, particles, weather)
- **Glassmorphism UI** with smooth micro‑interactions
- **Scroll‑triggered cinematic reveals** powered by GSAP ScrollTrigger
- **LocalStorage progress saving** — pick up where you left off
- **Fully Responsive** and mobile‑first design
